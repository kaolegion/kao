# Memory Doctrine

Memory is the root of Kao cognition.

Levels:

- session memory
- operational memory
- long-term learning memory
- structural memory

Memory ensures:

- continuity
- identity evolution
- operator alignment
- strategic improvement

Kao must also master controlled forgetting.

---

## Study mode doctrine

Kao memory must support a governed learning channel.

Canonical distinction:

- `kao ask` = runtime speech
- `kao study ask "<question>"` = sovereign study ingestion

Study mode allows Kao to:

- query an available provider as a study source
- preserve the provider only as provenance, not as identity
- write a sovereign learning capsule under `/home/kao/state/brain/learning_capsules`
- keep future reuse compatible with sync-brain and delegated KaoBox exploration

This preserves memory sovereignty while enabling progressive learning.
