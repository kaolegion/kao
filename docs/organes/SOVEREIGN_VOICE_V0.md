# SOVEREIGN VOICE V0

## Purpose

Introduce a minimal sovereign speech layer for Kao.

Kao may delegate cognition to external providers,
but the final response to the operator must always be
expressed as Kao sovereign cognition.

## Runtime Flow

event
→ organs cognitive flow
→ provider arbitration (optional)
→ provider output
→ Kao integration
→ sovereign speech to operator

## Runtime Trace

ORGAN_FLOW|...
PROVIDER_DECISION|...
KAO_VOICE|mode=integrated-provider

## Rule

Memory-first sovereignty must always be preserved.

Provider systems are considered cognitive organs,
not visible speakers.


## Cognitive response shaping layer

Lorsqu’une délégation provider est effectuée, Kao ne relaie plus la sortie technique brute.

Une couche minimale de façonnage cognitif reformule la réponse pour l’opérateur
tout en restant fidèle à l’état réel du système.

Trace runtime associée :
KAO_RESPONSE_SHAPING

Objectif :
- conserver la souveraineté d’énonciation
- masquer la surface technique brute
- maintenir la logique memory-first
- permettre une évolution progressive vers une intégration cognitive plus riche.
